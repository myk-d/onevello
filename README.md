# OneVello
#### Share once. Trust always.

> Keep your sensitive information out of chats, emails, and logs — securely and effortlessly.

OneVello is a zero-knowledge encrypted messaging platform. Your secrets are encrypted directly in the browser before being sent to the database, ensuring that even database administrators cannot access your raw text.

## 🚀 Key Features

* **Client-Side Encryption**: Uses AES-GCM via the `secure-channel-sdk` to protect data before it ever leaves your device.
* **One-Time Access**: Messages can be set to self-destruct immediately after the first view.
* **Expiration Dates**: Set a specific date and time after which the link becomes invalid.
* **Passphrase Protection**: Decryption is only possible with the correct user-defined passphrase.
* **Modern UI**: A minimalist, responsive interface built with custom-styled components.
