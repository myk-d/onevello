Open a secret

Three steps for the recipient: a sealed gate before anything is deleted, the passphrase prompt, and the revealed secret. The gate needs an app change: today a one-time secret is deleted as soon as the link page loads (§8.6 of the doc).

1 · Sealed gate

Shown before the secret is opened. It reads the metadata only (one-time, expiry, file) and explains that opening breaks the seal. An accidental open or a chat link preview that runs the page deletes nothing.

2 · Passphrase

The counter is always visible in mono. A wrong passphrase shows the danger alert with the attempts left.

3 · Revealed

The seal is broken. The text is in mono with one copy button; a one-time file can be downloaded once.
