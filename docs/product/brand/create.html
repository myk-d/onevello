Create a secret

Compose and options on one card: text, an optional file, the passphrase with generator and strength, expiry presets and the one-time switch. The file name warning is shown because the name and type are stored unencrypted.

Compose

Filled sample. Passphrase and expiry sit side by side on desktop and stack on mobile. The button names the action: "Seal and create link".

Sealing

Shown only while the real encrypt call runs (PBKDF2, about a second). The intact seal sits over the dimmed card; no fake steps.

Errors

Text over 10 000 characters (inline, with the exact overflow) and a failed save (alert, nothing stored).
