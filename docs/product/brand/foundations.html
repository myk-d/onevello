Foundations

Every colour is a --color-<role> token in assets/brand.css, with one light and one dark value. The contrast table below is computed live from those tokens with the WCAG 2.1 formula.

Palette

Paper and ink for the ground, navy as the action colour, burgundy wax (--color-seal) only for the mark and the seal moments. Danger stays an orange-red so it never reads as the wax.

Contrast

Text pairs need 4.5:1 (AA). Input borders, the focus ring and the seal mark are non-text and need 3:1.

Type

Source Serif 4 (titles), IBM Plex Sans (interface), IBM Plex Mono (values).

Components

Buttons with states, text input and textarea with counter, passphrase field with reveal toggle and generator, expiry presets, one-time switch, file drop zone, copy-link field, chips, alerts, toast, dialog, skeleton. Copy follows the language toggle in the nav.

Do and don't

Do
  • Say what happens and in which order: "Opening breaks the seal and deletes it."
  • Put the limit next to the promise, in one short clause.
  • Show every copied value in mono, the link in groups of four.
  • Remind to send the passphrase separately on the share screen and in the copied toast.
  • Use the wax colour only for the mark and the seal moments.
  • Keep one card with --shadow-card per screen.
Don't
  • "Military-grade", "unhackable", "100% secure", "no trace", "zero logs".
  • Serif below 20 px, in buttons, inputs, chips or alerts.
  • Wax-coloured buttons or text: the wax is not an action colour.
  • Italic links, links in green, or the passphrase in proportional type.
  • Fake "securing…" progress or a scramble animation.
  • Exclamation marks and emoji in system messages.
