When there is no secret

Five honest states instead of today’s single "viewed or expired" screen. Telling them apart needs app changes (§8.6): the code sends every failure, including a network error, to the same screen. Burned and not found look the same to the server once the document is deleted; the burned screen needs a small record that the link was opened.

Burned

The broken seal. Tells the recipient what to do if it wasn’t them.

Expired

Offline or load error

The only state with "Try again": nothing was opened or deleted.
