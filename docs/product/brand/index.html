OneVello: the sealed letter

The link is the envelope, the passphrase breaks the seal, and a seal breaks once. These pages hold the identity: tokens, components, logo, screens and the landing. The reasoning is in onevello-rebrand.md.

Owner decisions

  • Name: stays "OneVello".
  • Direction: B, Seal (Печатка), with C's mono treatment for every value the user copies (link, passphrase, counters).
  • Tagline: stays "Share once. Trust always." / «Надішліть раз. Довіряйте завжди.» The landing keeps the plain "what it can't protect against" list next to it.
  • Logo: S1, the broken seal (picked from five concepts after the first sketches were rejected). See Logo.
  • Where it lives: static HTML in this folder (no Figma). Tokens in assets/brand.css as --color-<role>, so they can move into src/index.css as they are.

The identity in one screen

Paper, navy ink and burgundy wax. Serif for titles only, Plex Sans for the interface, Plex Mono for values.
